# Учебник: первые сцены на GMS

Этот учебник — для тех, кто открыл песочницу впервые. За 10 коротких уроков вы
соберёте настоящую интерактивную сцену: точки, которые можно тащить мышью, живые
подписи, график с ползунком, анимацию и 3D-тело. Программировать раньше не нужно.

> **Как читать.** У каждого примера есть кнопка **«Открыть в редакторе»**. Нажмите её,
> поменяйте числа — и сразу увидите результат справа. Ломать не страшно: шаблоны и
> примеры всегда можно открыть заново.

Полное описание всех объектов и функций — во вкладке **«Справочник»** (переключатель
над содержанием слева).

## Урок 0. Как устроена песочница

Вверху — три вкладки:

| Вкладка | Для чего |
|---|---|
| **Редактор** | пишете код слева, сцена сразу появляется справа |
| **Конструктор** | рисуете точки и фигуры мышью, а код пишется сам |
| **Документация** | этот учебник и полный справочник языка |

Кнопки над редактором:

| Кнопка | Что делает |
|---|---|
| **Запустить** (`Ctrl` + `Enter`) | собрать и перезапустить сцену |
| **Автозапуск** | перезапускать сцену сама через долю секунды после каждой правки |
| **Шаблоны** | готовые заготовки: пустая сцена, треугольник, график, 3D… |
| **Мои сцены** | сохранить сцену под своим именем и вернуться к ней позже |
| **Примеры справочника** | открыть любой из 1400+ примеров с сайта и посмотреть, как он сделан |
| папка / стрелка | открыть файл `.gms` с компьютера / скачать код |
| `</>` | скачать готовую страницу `.html` — её можно открыть в любом браузере, без сайта |
| цепочка | скопировать ссылку, в которой уже лежит ваш код — отправьте её другу |
| лупа | найти и заменить текст (`Ctrl` + `F`, `Ctrl` + `H`) |
| клавиатура | список горячих клавиш (`F1`) |
| выравнивание, рамка | выровнять отступы, развернуть на весь экран |

Над сценой — кнопка **фотоаппарат** (сохранить снимок `.png`) и **перезапуск**.
Разделитель между кодом и сценой можно тянуть мышью, двойной щелчок возвращает
ширину по умолчанию.

> Код сохраняется в браузере сам: закройте вкладку, откройте снова — он на месте.
> Но это только в этом браузере. Чтобы не потерять работу, сохраняйте её в
> **«Мои сцены»**, скачивайте `.gms` или копируйте ссылку.

## Урок 1. Первая сцена

Любая программа GMS лежит внутри квадратных скобок `[ … ]`. Внутри — строки с
объектами и настройками. Вот самая маленькая сцена — одна точка:

```gms
[
show axes = true;
show grid = true;

new Point { name = "A"; pos = (2, 1); text = true("A") }
]
```

Разберём по словам:

- `show axes = true;` и `show grid = true;` — **настройки сцены**: показать оси и сетку.
  Каждая настройка заканчивается точкой с запятой.
- `new Point { … }` — **создать объект** «точка». В фигурных скобках — его поля.
- `name = "A"` — имя. По нему на точку будут ссылаться другие объекты.
- `pos = (2, 1)` — координаты x и y.
- `text = true("A")` — подпись рядом с точкой.
- Поля внутри `{ }` разделяются точкой с запятой `;`.

Попробуйте: откройте пример в редакторе, поменяйте `(2, 1)` на `(-3, 4)`. Потом
потащите точку мышью прямо в сцене — точки по умолчанию можно перетаскивать.

## Урок 2. Точки и отрезки

Отрезок строится по двум точкам — пишем их имена в `pos`:

```gms
[
show axes = true;
show grid = true;

new Point { name = "A"; pos = (-4, -2); text = true("A") }
new Point { name = "B"; pos = (4, -2); text = true("B") }
new Point { name = "C"; pos = (0, 3); text = true("C") }

new Line { name = "ab"; pos = (A, B) }
new Line { name = "bc"; pos = (B, C) }
new Line { name = "ca"; pos = (C, A) }
]
```

Тащите вершины — стороны следуют за ними. Так работает вся геометрия в GMS: объекты
**построены** на других и сами пересчитываются.

> **Внимание:** имена должны быть разными. Две точки `A` — частая ошибка: компилятор
> сообщит о повторе имени.

Ещё пара объектов, которые пригодятся сразу:

| Код | Что получится |
|---|---|
| `new Circle { name = "w"; center = A; radius = 3 }` | окружность с центром A |
| `new Point { name = "M"; homothety = B; center = A; ratio = 0.5 }` | середина отрезка AB |
| `new Point { name = "X"; line = "ab"; t = 0.3 }` | точка, которая ездит только по отрезку ab |

## Урок 3. Переменные и живое описание

**Переменная** — именованная ячейка со значением. Объявляется типом и именем:

```gms-snippet
float a = 2.5;      // дробное число
int n = 3;          // целое
string info = "";   // текст
bool on = true;     // да / нет
```

Под сценой можно показать текст — **описание**. Фигурные скобки `{имя}` внутри
описания подставляют значение переменной, и оно обновляется на лету:

```gms
[
description = "Привет! Число a = **{a}**"
show description = true;

float a = 7;
]
```

`**…**` делает текст жирным. В песочнице описание показывается только при
`show description = true;` — не забудьте эту строку.

## Урок 4. Update: сцена, которая считает

`Update { … }` — блок кода, который выполняется **каждый кадр** (60 раз в секунду).
В нём удобно пересчитывать то, что зависит от положения точек.

```gms
[
description = "Длина AB = **{len}**, середина: ({mx}; {my})"
show description = true;
show axes = true;
show grid = true;

new Point { name = "A"; pos = (-4, -2); text = true("A") }
new Point { name = "B"; pos = (3, 2); text = true("B") }
new Line { name = "ab"; pos = (A, B) }

string len = ""; string mx = ""; string my = "";
Update {
  len = format(ab.length, 2);
  mx = format((A.pos.x + B.pos.x) / 2, 1);
  my = format((A.pos.y + B.pos.y) / 2, 1);
}
]
```

Что здесь нового:

- `ab.length` — длина отрезка, `A.pos.x` — координата x точки A.
- `format(число, 2)` — округлить до двух знаков после запятой.
- Строки `len`, `mx`, `my` объявлены заранее, а в `Update` им присваиваются новые
  значения (без слова `string` — переменная уже есть).

Есть и `Start { … }` — он выполняется **один раз** при запуске сцены.

## Урок 5. График функции

Сначала описываем функцию словом `func`, потом рисуем её `draw Function` и указываем
**имя** функции в кавычках:

```gms
[
show axes = true;
show grid = true;

func f(x) = x^2 / 4 - 2;
draw Function { name = "gr"; f = "f" }
]
```

`^` — степень. Доступны `sin`, `cos`, `sqrt`, `abs`, `exp`, `log` и ещё сотни функций
(список — в справочнике, раздел [Встроенные функции](#встроенные-функции)).

> **Внимание:** `f = "x^2"` не сработает — в `draw Function` пишут имя функции,
> а не формулу.

## Урок 6. Ползунки и кнопки

Элемент управления — `new UI`. Ползунок связывается с переменной полем `variable`:

```gms
[
description = "y = **{k}**·sin(x)"
show description = true;
show axes = true;
show grid = true;

float k = 1;
func f(x) = k * sin(x);
draw Function { name = "gr"; f = "f" }

new UI { name = "s"; type = slider; label = "k"; variable = k; min = -3; max = 3; step = 0.1 }
new UI { name = "b"; type = button; label = "Сбросить"; action = "k = 1" }
]
```

- `type = slider` — ползунок (пишется **без кавычек**), `min`, `max`, `step` — его границы и шаг.
- `type = button` — кнопка; в `action` в кавычках — код, который выполнится по нажатию.
- Другие виды: `toggle` (переключатель), `input` (поле ввода), `select` (список).

Двигайте ползунок — график меняется, потому что функция `f` использует переменную `k`.

## Урок 7. Анимация

`animate("имя", цель, секунды, плавность, задержка, режим)` плавно меняет переменную.
Остаётся в `Update` переставлять точку:

```gms
[
description = "Точка бегает по окружности"
show description = true;
show axes = true;
show grid = true;

float t = 0;
new Point { name = "O"; pos = (0, 0); dynamic = false; text = true("O") }
new Circle { name = "w"; center = O; radius = 4 }
new Point { name = "P"; pos = (4, 0); dynamic = false; text = true("P") }
new Line { name = "op"; pos = (O, P) }

Start { animate("t", 2 * pi, 4, "linear", 0, "loop"); }
Update {
  P.pos.x = 4 * cos(t);
  P.pos.y = 4 * sin(t);
}
]
```

- `dynamic = false` — точку нельзя тащить мышью (ею управляет программа).
- Режимы: `"once"` — один раз, `"loop"` — по кругу, `"pingpong"` — туда и обратно.
- Плавность: `"linear"`, `"easeIn"`, `"easeOut"`, `"easeInOut"`.

## Урок 8. Условия, циклы и свои функции

Внутри `Start`, `Update` и кнопок работает обычная логика:

```gms
[
description = "{info}"
show description = true;

float n = 5;
new UI { name = "s"; type = slider; label = "n"; variable = n; min = 1; max = 12; step = 1 }

Function fact(k) {
  float r = 1;
  repeat (k) { r *= i + 1; }
  return r;
}

string info = "";
Update {
  string kind = "нечётное";
  if (n % 2 == 0) { kind = "чётное"; }
  info = "n = " + n + " — " + kind + ", n! = " + fact(n);
}
]
```

| Конструкция | Пример |
|---|---|
| условие | `if (a > 0) { … } else { … }` |
| повторить N раз | `repeat (5) { … }` — внутри счётчик `i` = 0, 1, 2, 3, 4 |
| пока условие верно | `while (k < 100) { k *= 2; }` |
| перебрать список | `for (x in L) { s += x; }` |
| своя функция | `Function имя(a, b) { …; return …; }` |

> **Внимание:** `i++` и `for (i = 0; i < n; i++)` в GMS нет. Пишите `i += 1` и `repeat`.

## Урок 9. Вкладки: показать и спрятать группу

`new Claster` собирает объекты в группу, а её поле `active` включает и выключает
показ. Две кнопки — и получились вкладки:

```gms
[
show grid = true;

new Point { name = "A"; pos = (-3, 0); text = true("A") }
new Point { name = "B"; pos = (3, 0); text = true("B") }
new Line { name = "ab"; pos = (A, B) }
new Circle { name = "c"; center = A; radius = 3 }

new Claster { name = "t1"; elements = (B, ab); active = true }
new Claster { name = "t2"; elements = (c); active = false }
new UI { name = "b1"; type = button; label = "Отрезок"; action = "t1.active = true; t2.active = false" }
new UI { name = "b2"; type = button; label = "Окружность"; action = "t1.active = false; t2.active = true" }
]
```

## Урок 10. Третье измерение

В 3D у точек три координаты, а объекты называются с приставкой `3D`. Сцену можно
вращать мышью (на телефоне — пальцем), колесо — масштаб.

```gms
[
field width = 10; field height = 8; field depth = 10;
camera start rot = (30, 70);
show axes = true;

new Point3D { name = "A"; pos = (-2, -1, -2); text = true("A") }
new Point3D { name = "B"; pos = (3, -1, -1); text = true("B") }
new Point3D { name = "C"; pos = (0, -1, 3); text = true("C") }
new Point3D { name = "D"; pos = (0, 3, 0); text = true("D") }
new Line3D { name = "ab"; pos = (A, B) }
new Line3D { name = "bc"; pos = (B, C) }
new Line3D { name = "ca"; pos = (C, A) }
new Line3D { name = "ad"; pos = (A, D) }
new Line3D { name = "bd"; pos = (B, D) }
new Line3D { name = "cd"; pos = (C, D) }
]
```

Готовые тела — `new Primitive { name = "k"; type = cube; edge = 4 }` (куб, шар,
цилиндр, конус, пирамида и другие). Подробности — в справочнике, раздел
[3D-сцены](#3d-сцены).

## Если что-то не работает

Ошибки показываются под кодом красным, а номер строки с ошибкой подсвечивается слева.
**Щёлкните по ошибке** — курсор перейдёт к нужной строке.

| Сообщение или признак | Что проверить |
|---|---|
| «Не закрыта скобка «{»» | у объекта нет закрывающей `}` — допишите её |
| «Лишняя закрывающая скобка» | скобка без пары: удалите её или найдите пропущенную открывающую |
| «Не найден блок в квадратных скобках» | весь код должен быть внутри `[ … ]` |
| «Неизвестный ключ …» | опечатка в названии поля или настройки; часто — пропущена `;` или `}` строкой выше |
| сцена пустая, ошибок нет | объекты вне поля: посмотрите на координаты или увеличьте `field width` |
| график не рисуется | в `draw Function` должно быть имя функции: `f = "f"` |
| ползунок не двигает график | функция должна использовать переменную из `variable` |
| текст `{x}` не меняется | переменная `x` объявлена? Значение присваивается в `Update`? |

Ещё советы:

- Нажмите `Ctrl` + `Space` — редактор подскажет поля объекта, функции и имена.
- Кнопка «Выровнять отступы» помогает увидеть, где не хватает скобки.
- Откройте похожий пример через **«Примеры справочника»** и сравните со своим кодом.
- Частые ошибки собраны в справочнике: [Частые ошибки](#частые-ошибки).
